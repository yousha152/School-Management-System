# School Management System

A dual-implementation **School Management System** featuring a complete CLI execution engine written in Python and a responsive dashboard Web Frontend interface built using Vanilla HTML5, CSS3, and JavaScript.

## 🚀 Key Modules & Capabilities

- **Student Operations Management**: Register new students with unique IDs, view full roster data, search profiles, and modify contact details.
- **Faculty Management**: Add teachers, view active subject assignments, and look up faculty contacts.
- **Attendance Registry**: Record daily student attendance (Present, Absent, Leave) and calculate aggregate percentage ratios.
- **Academic Scorecard**: Record subject-wise examination scores (0–100 scale), auto-compute overall percentage, and evaluate final letter grades (`A+` down to `F`).
- **Fee Ledger**: Log monthly fees, compute remaining dues, and automatically calculate payment status (`Paid` vs `Pending`).
- **Administrative Summary**: Aggregate total student headcounts, active teaching staff, and current pending fee balances.
